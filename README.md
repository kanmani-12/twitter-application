# Chirp

A mobile-only Twitter-style demo built with HTML, CSS, and JavaScript.

## Run

Open `login.html` in a browser.

## Features

- Create posts, like, repost, reply, and view replies
- Explore trends and follow users
- Notifications, profiles, and direct messages
- Local browser storage for posts, follows, and sign-in state

## Files

- `login.html` — Sign-in screen
- `index.html` — Feed
- `explore.html`, `notifications.html`, `messages.html`, `chat.html`, `profile.html` — App screens
- `style.css` — Mobile UI styling
- `data.js`, `app.js` — Demo data and interactions
